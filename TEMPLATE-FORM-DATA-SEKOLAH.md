# Template Formulir Pengumpulan Data — Website SDN 3 Way Galih

Dokumen ini adalah **acuan pembuatan Google Form** untuk mengumpulkan data dari pihak sekolah.
Setiap bagian di bawah = **1 section** di Google Form. Tandai `(wajib)` untuk field yang harus diisi.

> **Cara pakai:** salin tiap section ke Google Form. Kolom "Tipe pertanyaan" menunjukkan jenis input yang dipakai. Contoh jawaban boleh dicantumkan sebagai *help text* agar pengisi paham formatnya.

## Catatan untuk Pembuat Form

1. **Aktifkan unggah file** di Google Form (butuh akun Google Workspace sekolah, atau minta file dikirim via Google Drive lalu tempel link-nya).
2. **Batas ukuran**: minta foto maksimal 5 MB per file agar mudah diunggah ke website.
3. **Data yang sudah terisi** di website saat ini bersifat contoh/sementara — semua jawaban form ini akan **menggantikannya**.
4. **Prioritas jika sekolah keberatan mengisi semua**: Section 1, 3, 4, 5, dan 14 sudah cukup untuk website tampil dengan data asli. Sisanya bisa menyusul.
5. Setelah form diisi, data dimasukkan ke **panel admin website** (`/admin`) — tidak perlu diketik ulang ke kode.
